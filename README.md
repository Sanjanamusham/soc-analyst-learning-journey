# SOC Analyst Learning Journey

Documenting my hands-on journey toward entry-level IT Support and SOC Analyst roles.

## Featured Projects

### [SOC Alert Investigation & Incident Response Lab](projects/soc-alert-investigation-lab/README.md)
A VMware-based lab using Splunk Enterprise to collect Windows and Linux logs and practice SOC alert investigation.

**Verified work:** Multi-source log ingestion (Kali syslog and Windows Application, Security, and System logs) and an evidence-backed Windows Event ID 4625 investigation. The Incident 01 verdict was inconclusive/local authentication activity; no external brute-force attack was confirmed.

**Tools:** VMware Workstation, Splunk Enterprise 10.0.1, Windows Server 2022, Kali Linux, Splunk Universal Forwarder, SPL.

### [IT Support & Active Directory Administration Lab](projects/it-support-active-directory-lab/README.md)
A home lab for practicing help-desk, desktop support, Windows administration, Active Directory, DNS, user account management, domain joining, and troubleshooting.

**Verified work:** Created an Active Directory domain in a virtual lab, joined a Windows client, created and managed a test user, and practiced account disable/enable and password reset tasks.

**Tools:** VMware Workstation, Windows Server, Windows client, Active Directory Users and Computers, DNS, PowerShell.
