# SOC Analyst Learning Journey

Documenting my path to becoming a SOC analyst.

## Featured Hands-on Project

### [SOC Alert Investigation & Incident Response Lab](projects/soc-alert-investigation-lab/README.md)

A VMware-based lab using Splunk Enterprise to collect Windows and Linux logs and practice SOC alert investigation.

**Verified work:** Multi-source log ingestion (Kali syslog and Windows Application, Security, and System logs) and an evidence-backed Windows Event ID 4625 failed-authentication investigation. The Incident 01 verdict was inconclusive/local authentication activity; no external brute-force attack was confirmed.

**Tools:** VMware Workstation, Splunk Enterprise 10.0.1, Windows Server 2022, Kali Linux, Splunk Universal Forwarder, SPL.
